\# AI Based Document Forgery Detection



\## About the Project



AI Based Document Forgery Detection is a web-based application that uses deep learning to analyze document images and predict whether a document is likely authentic or potentially forged.



\## Technologies Used



\- Python

\- PyTorch

\- ResNet18

\- Flask

\- Pillow

\- PyMuPDF

\- HTML

\- CSS

\- Computer Vision



\## Features



\- Upload document images

\- Upload PDF documents

\- AI-based forgery detection

\- Forgery probability

\- Authenticity probability

\- Simple web-based interface



\## Machine Learning Model



The project uses a ResNet18 deep learning model trained to classify document images into two categories:



\- Authentic

\- Forged
